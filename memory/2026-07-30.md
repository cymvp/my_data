## 1. 今天获得的知识与技能

- **多轮会话里"正则串课"是最危险的一类缺陷（prove 今天抓到的最严重 bug）**：用户问"721717 这门课的考试，哪几道题正确率最低？"，系统答的却是课程 **752468** 的数据——**不是拒答，而是静默换了一门课回答**。根因是会话层用正则从问题里抽课程 ID 的逻辑有缺陷（记为 KI-2），把上一轮的焦点课程带了进来。修法：修正则 + 顺手修 KI-3（拒答时把已解析的参数带出去，否则下一轮建立不起焦点）。**这类"答得出数字但答的是另一个对象"的缺陷比拒答严重得多**，因为用户看不出来。
- **`limit=None` 会被序列化成字符串 "None" 让上游 500**：`_lookup` 的 `limit` 默认 `None`，而 `_course_of_exam` 没传，请求体里 `limit_num=None` 发到 apolo，直接 HTTP 500。排查过程有价值：先手工查同一张表成功 → 判断 SQL 本身没问题 → 隔离到参数序列化层。**默认值 None 传给外部接口，是一类容易漏的坑。**
- **拒答理由必须说真原因，"no_rows" 是掩盖**：一个测评小节查不到答题数据，系统拒答理由写"查询结果为 no_rows"，但**真正的原因是这个小节根本不是测评小节**（`vote_session.type=1` 是投票小节，`type=10` 才是测评）。用户看到"无数据"会以为是数据缺失，实际是问错了对象。**拒答理由的信息量决定用户能不能自己纠正问题。**
- **本地数仓的可用数据远比我以为的多（一个"以为受限所以绕路"的错误）**：我为了回答两门课的问题走了 apolo（线上），理由是"本地只有三门测试课"。实际查下来**本地数仓里有 12 场带答题数据的考试**（企业 1791、227、2600、2684 都有），而且**全是 `question_mode=3`（固定题目、非随机抽题）**——正是之前一直缺的场景，逐题正确率只在这类考试上才有意义。**教训：绕路走线上之前，先实测本地到底有什么，不要凭印象判断数据范围。**
- **`question_mode=3` 是逐题正确率有意义的前提**：随机抽题模式下每份试卷的 `question_id` 是题目实例、不是题库题（之前发现过一个测评小节 62296 条答题分属 62270 个 question_id，"哪道题错得最多"毫无意义）。固定题目模式才能做逐题分析。

- **日文药品文献的召回难点：同义词与花括号扩展到底起不起作用（csrs 今天的核心排障）**：用户问"ジャディアンス（JAD，欧唐静）の禁忌"，检索命中的是另一个药（TRD）的添付文書。关键机制：**query 里花括号写的同义词（如 `{ジャディアンス:[JAD,ジャド]}`）会被 ES 的 tokenizer 当成普通 token 参与 BM25 打分**——也就是说它**确实起作用了，但作用方向是错的**：`エンパグリフロジン`（恩格列净，ジャディアンス 的通用名）在 TRD 的添付文書里出现 127 次，BM25 强命中、rerank 打 0.9，把错误文档冲到候选池第一。**同义词扩展是双刃剑：它提高召回，但会把"通用名在别的药文档里高频出现"这种噪音也放大。**
- **日文药品文献的三类文档要分清**（csrs 语料）：**添付文書**（官方说明书，法定文件，最权威）、**医薬品インタビューフォーム（IF）**（面向医疗人员的详细资料）、**RMP（医薬品リスク管理計画書）**（风险管理计划书）。回答"禁忌症"这类问题应以添付文書为准。今天实测拿到的正确答案是"1型糖尿病を合併する慢性心不全患者／慢性腎臓病患者：投与を避けること"。
- **追踪网格缺"时间记忆"这个策略层缺陷（今天做 T 自检的最大发现，比之前所有 bug 都值钱）**：中际旭创今天振幅 19.77%，追踪网格在价格上行途中连续四次卖出（826.19 / 836.62 / 847.14 / 858.01），随后价格涨到 900 以上再回落时又连续四次买入（890.48 / 900.61 / 889.65 / 878.91）。**卖均价 841.99、买均价 889.91，每股倒亏 47.92 元，四笔 400 股全执行 = 亏 76,676 元**（未含手续费）。**这不是 bug，是追踪网格在强趋势中的固有弱点**：它把底仓卖在半山腰，中枢重锚上移后又追高买回。**风控确实在工作（卖出期 `flags=停买`、买入期 `flags=停卖`），但它只做单边静默、没有跨时段记忆**——不知道"你两小时前刚在 858 卖过，现在 890 的买档是亏的"。**根本原因：追踪网格只有"当前中枢在哪"的空间记忆，缺"今天在什么价位卖过"的时间记忆。**
- **A 股信用账户（融资）的集中度限制与科创板新股规则（今天查证）**：**科创板股票上市首日即可作为融资融券标的**，不用等主板那个 3 个月要求——所以融资买入和**融券做空**在制度上首日就开放（只是券源主要来自战略配售转融通、供给有限）。券商在新股前 5 日实际收紧的是三样：**保证金比例 140–150%**（常规 100%）、**担保品折算率仅 20–30%**、**单一标的集中度**（一般标准不超过信用账户持仓 80%，而招商证券对长鑫只给 30%）。另外**无涨跌幅限制期间有两档临时停牌：相对开盘价涨跌 30% 和 60% 各停 10 分钟**——"无上限"不等于完全没有刹车。
- **"放量上涨是好是坏"取决于位置和收盘形态**：低位放量上涨是资金进场（好）；高位放量上涨可能是主力借利好派发（危险）。更细的判据是**收盘位置**：放量且收在当日高位附近是有效放量；**放量但冲高回落、留长上影线，说明上方抛压明显、卖方在高位赢了这一局**。辅助判据是**成交均价 vs 收盘价**——均价明显低于收盘说明大量成交发生在更低价位、盘中经历剧烈换手而非单边上攻。

## 4. 经验与教训

- **"静默换对象作答"比拒答严重得多，必须优先修**：prove 那个正则串课 bug 让系统用课程 752468 的数据回答关于 721717 的问题——**数字是真的，对象是错的，用户看不出来**。这类缺陷和 [[2026-07-24]] 的 course_id 静默降级、[[2026-07-27]] 的 cognee 静默建库是同一族。**判断原则：凡是"从用户输入里抽取标识符"的逻辑，都要问"抽错了会怎样——是报错还是照样给出一个答案"。**
- **绕路走线上之前，先实测本地到底有什么**：我以为"本地只有三门测试课"所以走了 apolo，实际本地数仓有 12 场带答题数据的考试、而且正是缺的那种固定题目模式。**凭印象判断数据范围会导致不必要的绕路，还会让排障结论建立在错误的环境上。**
- **拒答理由的信息量决定用户能不能自救**：写"no_rows"用户以为是数据缺失；写"这个小节 type=1 是投票小节、不是测评小节"用户立刻知道自己问错了对象。**拒答不是终点，理由才是产品。**
- **代码溯源优于抓包，尤其当源码本地可读时**：今天浏览器挂不上反而促成了更硬的结论——`biz-common` 源码在本地，精确 SQL 直接读到，还发现了 **DDL 与代码常量不一致**这种抓包永远看不到的矛盾。
- **主动区分"推理"与"验证"，并且去验**：今天有一处我上一轮推理出的结论被真实数据推翻（差集为 0）。做法是对的：**标注"那句话我是推理出来的、没验过"，然后去查实**。这是 [[2026-07-26]]「你验证过么」那条教训的正确执行。
- **竞价数据样本太薄，不足以给"板块 vs 个股"定性**：早盘我看竞价（中际旭创 -4.31%、新易盛 -0.28%）判断"是个股事件不是板块问题"，开盘后新易盛 -12.23% 跌得更多，**归因错了**。**竞价只有几分钟的撮合，分化可能是暂时的；板块性判断要等开盘后的量能确认。**
- **同一个策略缺陷要区分"bug"和"设计固有弱点"，后者更难但更值钱**：做 T 那个"卖低买高倒亏 7.6 万"不是代码写错，是**追踪网格只有空间记忆（中枢在哪）、缺时间记忆（今天在什么价位卖过）**。修 bug 是让代码符合设计；修这个是**给设计补一条它缺失的约束**。识别出这个区别，才知道该改哪一层。
- **同义词扩展是双刃剑,要看它把噪音也放大到哪里**：csrs 那个日文药品召回错误，根因是同义词（通用名 `エンパグリフロジン`）**确实进了 ES 打分、确实起了作用，但作用方向错了**——因为这个通用名在另一个药的文档里出现 127 次。**评估召回增强手段时，不能只看"能不能召回目标"，还要看"会不会把强噪音也顶上来"。**
- **给投资咨询做机制分析时，要检查用户假设里的隐含前提**：用户问"不限制融资额度后会不会大涨"，隐含前提是"现在不能融资"。查证发现**科创板新股上市首日就能融资融券**，所以"放开"只是券商风控参数的量变、不是制度质变；而且**放开的是整套信用交易参数，融券做空也在其中**——用户只算了做多这一半。**另外因果可能是反的：券商放松风控的前提是波动率下降，通常是"稳了才放开"而不是"放开才涨"。**
- **杠杆 + 无涨跌幅限制 + 小流通盘的组合要明确警示**：±20% 生效**不等于变安全**——它只封单日不封累计（SpaceX 16 天跌 13 天累计 -50%），而且**跌停时买盘消失、想卖卖不掉**，对融资账户是"担保比例被击穿却无法自救"的陷阱；流通盘只有 6.73% 的股票跌停封死概率更高。**说清这个机制比给方向判断有用。**
- **自己写进定时任务或反复陈述的事实也要复核**：我连续几天说"今晚 Arm 财报"，实际 Arm 是 7/30 才发。**高频重复的说法容易固化成"已知事实"而不再被检验。**
